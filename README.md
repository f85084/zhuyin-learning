# 寶可夢注音圖鑑

以寶可夢圖片與繁體中文名稱為主題的兒童注音學習頁面。每個中文字右側都會顯示對應的直式注音，聲調則排列在注音符號右邊。

## 功能

- 收錄全國圖鑑 001–1025 的寶可夢名稱、注音與圖片。
- 單頁整合看圖認讀、看圖選名字、看注音選圖片與缺字挑戰四種題型，可直接列印成完整學習單。
- 可依名稱、圖鑑編號及第一至第九世代篩選。
- 每次隨機顯示 6、9、12 或 18 題。
- 可遮住注音進行自我練習，再顯示答案核對。
- 支援手機、平板、桌面瀏覽及 A4 列印。
- 純靜態網站，不需要安裝或編譯。

## 使用方式

透過靜態網站伺服器開啟專案根目錄，再進入 `index.html`。頁面會讀取 `pokemon-zhuyin.json`，並依圖鑑編號載入 `assets/pokemon` 內的圖片。
